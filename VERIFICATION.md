# Проверка версии 0.2.0

Проверено на Windows 11 x64, Python 3.12.11, PySide6 6.12.0, google-genai 2.34.0, HTTPX 0.28.1, socksio 1.0.0, MKVToolNix 103.0.

- Повторный полный прогон `pytest`: **59 тестов прошли**, без пропусков. Включены сохранность ASS/SRT, кодировки, склонённые формы, регистр, границы слов, длинные совпадения, конфликты, исключения, защита от внедрения тегов, пропуск караоке/рисунков, сохранение проекта и отмена.
- Немедленная отмена: реальный асинхронный Gemini SDK подключён к трём намеренно зависающим локальным серверам (ожидание HTTP-ответа, SOCKS5 и TLS). От нажатия «Отменить» до восстановления интерфейса — 15–16 мс. Проверены закрытие сокета, работа таймера интерфейса во время ожидания, отсутствие поздних карточек/ошибок/кэша и запуск следующей задачи. После изменения повторно прошёл живой анализ искусственного диалога через `socks5://localhost:2080`.
- Сборка с немедленной отменой: `dist/instant-cancel/SubsRenamer.exe`. Изменённые модули в архиве EXE сверены с текущими исходниками. Нативный запуск подтвердил приветственный экран. Встроенная диагностика EXE с живым запросом через прокси прошла: `embedded_key_available`, `mkv_extract_ok`, `live_alias_grouping_ok`, `ok` — `true`. Отчёт: `.cache/packaged-instant-cancel/report.json`.
- Проверены вымышленные ответы Gemini: дубли, несуществующие имена и ссылки, отсутствие доказательств объединения, кэш, повреждённый JSON с повтором, отмена, скрытие исходного текста исключений.
- Создан настоящий MKV с двумя текстовыми дорожками: выбор русской дорожки и извлечение прошли. Утилиты из портативной сборки запускаются.
- Экспорт сезона из 25 синтетических файлов прошёл; оригиналы не изменились, тайминги сохранены, повторная запись блокируется. При ошибке записи одного файла остальные обрабатываются.
- Проверена последовательность фоновых задач Qt и исключение изменения через предпросмотр.
- Готовый EXE запущен и проверен через Windows UI: импорт папки ASS/SRT, ручное добавление карточки, изменение написания, предпросмотр, отображение причины пропуска караоке и экспорт двух файлов.
- Статическая проверка `ruff check src tests scripts` прошла.
- Проверены загрузка ключа из `.env` при разработке и встроенного ресурса в frozen-режиме, нормализация SOCKS5, отклонение авторизации и неверных адресов, распаковка и кэш встроенных утилит.
- Официальный Gemini SDK проверен через настоящий локальный SOCKS5-сервер с искусственным ответом: без авторизации, с передачей имени удалённого сервера прокси. `ALL_PROXY` / `NO_PROXY` не меняют маршрут. Проверен отказ прокси без прямого резервного подключения. Тест выполнялся вне сетевой песочницы, только через loopback с искусственным ключом.

Живая проверка `gemini-3.8-flash` через `socks5://localhost:2080` **прошла**: на искусственном диалоге имя «Рэн» и варианты прозвища «Лис», «Лисом» объединены в одну карточку. Скрипт `scripts/live_check.py` позволяет повторить проверку. Прямое подключение ранее отклонялось по региону; проверенный маршрут через предоставленный прокси работает.

Создан **dist\SubsRenamer.exe**, около 88,8 МиБ. Встроены ключ из приватного `.env`, Python/Qt, SOCKS5-поддержка, архив нужных утилит MKVToolNix, лицензии и соответствующие исходники. Архив EXE проверен: ключ совпадает с `.env` (значение не выводилось), архив утилит присутствует, временный файл ключа сборщика удалён. Исходники, тесты, примеры и документация не содержат значения ключа.

Копия EXE запущена из отдельной папки без `.env` и `vendor`, с очищенными переменными API-ключей. Встроенный ключ загружен, утилиты распакованы, двухдорожечный MKV создан и русские субтитры извлечены. Живой анализ Gemini через SOCKS5 также прошёл. Диагностический отчёт: `embedded_key_available: true`, `mkv_extract_ok: true`, `live_alias_grouping_ok: true`, `ok: true`.

Windows-интерфейс новой сборки проверен: вкладка «Имена», настройки модели и SOCKS5 без полей внешнего ключа и MKVToolNix. Адрес `socks5://localhost:2080` сохранён и подтверждён при повторном открытии настроек.

Изменение импорта: четыре верхние кнопки заменены одной «Добавить», открывающей выбор папки. Адаптированный GUI-тест проверяет нажатие этой кнопки, рекурсивное чтение выбранной папки, пропуск постороннего TXT и последующее редактирование. Тест и Ruff прошли.

Текущий интерфейс: стартовый экран содержит одну кнопку «Выбрать папку с субтитрами». После выбора папки открывается основной экран без кнопки «Добавить»; внизу слева вместо текстового статуса находится «Изменить папку». Старый проект заменяется только после успешного импорта нового сезона. Три GUI-теста прошли: импорт и редактирование; отмена и восстановление кнопки поиска; приветственный экран, отмена выбора, отказ от смены несохранённого проекта, успешная смена сезона с очисткой карточек/исключений/предпросмотра, сохранность проекта при пустой папке и повреждённых файлах. Ruff прошёл.

«Найти имена» расположена в нижнем правом углу и превращается в «Отменить» во время фоновой операции. Крупного заголовка, меню «Проект» и строки «01 / ИСТОЧНИКИ…» нет. Открытие и сохранение проекта доступны через Ctrl+O / Ctrl+S. Разделители столбцов сохраняются по всей высоте таблиц. Текущая сборка находится в `dist/welcome/SubsRenamer.exe`; открытые предыдущие версии не закрывались.

После восстановления лимитов завершена ручная проверка последней EXE-сборки: приветственный экран содержит одну кнопку; она открывает системный выбор папки. Выбрана папка `examples`, автоматически прочитаны два файла ASS/SRT (8 реплик), открыт основной экран. Подтверждены отсутствие верхней кнопки «Добавить» и статусной надписи, расположение «Изменить папку» внизу слева и «Найти имена» внизу справа. Полный набор из 53 тестов и Ruff повторно прошли. Незавершённых изменений по последнему запросу не выявлено.

Реальные сезоны пользователя в проверке не участвовали. Это первая версия; группировку имён и ников следует проверять в интерфейсе перед экспортом.
