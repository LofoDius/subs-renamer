# Subs Renamer

Windows-приложение для замены часто встречающихся японских имён в русских субтитрах целого сезона. Gemini находит имена, фамилии, прозвища и словоформы и предлагает объединить их в карточки. Вы проверяете группы, задаёте желаемые написания и сохраняете отдельные субтитры.

## Быстрый запуск

Откройте **dist\SubsRenamer.exe**. Это один переносимый файл: Python, Qt, SOCKS5-поддержка и нужные утилиты MKVToolNix включены внутрь. При запуске компоненты распаковываются автоматически; устанавливать зависимости и указывать их пути не нужно. Ключ Gemini встроен при сборке, запросы расходуют квоту его проекта Google.

1. В «Настройки Gemini» укажите SOCKS5-прокси без авторизации, например `socks5://localhost:2080` или `localhost:2080`. Пустое поле означает прямое подключение. Модель по умолчанию: `gemini-3.8-flash`. Список загружается из API и содержит только рекомендованные модели: `gemini-3.8-flash` (основной вариант), `gemini-3.1-pro-preview` (сложные контекстные связи), `gemini-3.5-flash-lite` (экономичный вариант). Кнопка «Обновить» повторяет запрос через введённый прокси. Специализированные модели изображений и аудио исключены.
2. На приветственном экране нажмите «Выбрать папку с субтитрами» и выберите папку сезона. Откроется основной экран, все ASS, SRT, MKV и `.crt` с содержимым SRT из неё и подпапок будут загружены автоматически. Остальные файлы и уже созданные `.renamed` пропускаются. Также можно перетащить папку в окно приложения.
3. Для MKV приложение само выберет единственную русскую текстовую дорожку. При неоднозначности выберите её в диалоге; выбор определяется для каждого файла отдельно.
4. Нажмите «Найти имена» в нижнем правом углу. Во время работы эта же кнопка становится «Отменить», после завершения, ошибки или отмены возвращается в исходное состояние. Она также отменяет импорт и сохранение, если выполняется одна из этих операций. Во вкладке «Имена» проверьте предложения Gemini: объединяйте карточки с Ctrl/Shift, отделяйте варианты, добавляйте пропущенные имена. Группы сортируются по сумме упоминаний, без порога частоты.
5. В карточке введите только «Новое имя (именительный падеж)» и нажмите «Составить варианты с Gemini». Например, для `Рэн → Иван` Gemini составит `Рэна → Ивана`, `Рэну → Ивану` и остальные найденные формы с учётом контекста. Проверьте результат в таблице: любые замены можно исправить вручную или очистить, чтобы не менять вариант. Другие фамилии и прозвища сохраняются, если они не являются формами заменяемого имени; для их переименования отделите их в отдельную карточку. Повторная генерация обновляет все замены карточки. Поле нового имени и готовые варианты сохраняются в проекте. Род и остальной текст реплик не переписываются.
6. Снимайте галочки в контекстах, если слово относится к другому человеку или является омонимом. Во вкладке проверки можно исключить отдельные изменения; обновление предпросмотра возвращает исключённые строки с пустыми галочками.
7. Сохраните результат в выбранную папку. Сохраняются структура подпапок и формат: `episode.renamed.ass`, `episode.track3.renamed.srt`. Существующие результаты не перезаписываются. Рядом создаётся JSON-отчёт о заменах и пропусках. Если операция отменена, уже сохранённые файлы остаются.

«Сохранить проект» (`Ctrl+S`) сохраняет текст исходных субтитров, карточки, замены и исключения. «Открыть проект» (`Ctrl+O`) восстанавливает их без повторного извлечения и запросов Gemini. Команды доступны через эти горячие клавиши; отдельного меню проекта нет. Не публикуйте проекты с чужими субтитрами в репозитории.

Кнопка «Изменить папку» расположена внизу слева вместо текстового статуса. Она загружает другой сезон, предлагая сохранить несохранённый проект. Текущий набор заменяется только после успешного чтения новых субтитров; отмена выбора, отмена загрузки, пустая папка и полностью повреждённые файлы не стирают текущий проект. Отдельной кнопки «Добавить» на основном экране нет. Ход работы показывает индикатор прогресса; подробности доступны в его подсказке. Ошибки по-прежнему показываются отдельными сообщениями.

Если Gemini блокирует содержимое, приложение пропускает этот блок и продолжает анализ. Файлы, в которых заблокированы все блоки, выделяются красным на шаге «Файлы»; причина указана в подсказке. Даже если пропущены все файлы, переход к именам и проверке остаётся доступным. При блокировке объединения имён уже найденные варианты сохраняются.

## Что сохраняется

Приложение редактирует исходные участки видимого текста без пересборки документа. Временные метки, структура реплик, стили, поля ASS и теги вокруг имени остаются прежними. Выход — UTF-8; при загрузке поддерживаются UTF-8, UTF-16 с BOM и Windows-1251. Неподдерживаемую кодировку сначала конвертируйте в редакторе субтитров.

Оригиналы не изменяются. Видео не перекодируется. В MKV результат обратно не упаковывается. Временные метки извлечённой дорожки сохраняются в пределах точности ASS/SRT.

Шрифты из вложений ASS-дорожек извлекаются в `fonts` рядом с результатом. Внешний ASS не содержит шрифты: установите их штатным способом Windows или подключите в проигрывателе. Некоторые проигрыватели используют вложенные в открытый MKV шрифты, но это не универсально. Выберите внешнюю исправленную дорожку в проигрывателе; автоматическая загрузка файла с суффиксом `.renamed` зависит от его настроек.

## Ограничения первой версии

- PGS/VobSub и надписи, являющиеся частью изображения видео, требуют OCR и не обрабатываются.
- Имя внутри сложной разметки (теги посреди имени), караоке и векторная графика ASS пропускаются с причиной в предпросмотре и отчёте. Обычные теги до и после имени поддерживаются.
- Gemini может ошибаться в именах и связях между никами. Проверяйте карточки и контексты. Ссылка на существующую реплику подтверждает наличие текста, а не правильность вывода модели.
- Частота считается по тексту реплик после проверки вхождений. Титры и песни отсеиваются моделью по контексту, а не гарантированным классификатором; при необходимости удаляйте лишние варианты вручную.
- Система находит только обращения, присутствующие в тексте. Сведения из внешних баз персонажей не используются.
- Границы имён учитывают буквы и цифры; японские суффиксы через дефис остаются после замены имени. Замены не каскадируют. При перекрытии выбирается самое длинное настроенное совпадение.
- Применение замен не нацелено на повторную обработку уже исправленных файлов. Повторный экспорт из проекта всегда выполняется по сохранённому оригиналу.

## Данные и ключ

В Gemini передаётся только текст выбранных реплик, имена файлов, идентификаторы и кандидаты; видео и шрифты не отправляются. В сборке API-ключ берётся из встроенного ресурса, внешний `.env` для запуска EXE не нужен. Ключ не копируется в проекты, настройки или сообщения об ошибках.

Приватный EXE содержит ключ, который можно извлечь из файла. Не публикуйте такой EXE или `.env` в GitHub. Публикуются исходники и `.env.example` без ключа; каждый собирает приложение со своим ключом. Ротация встроенного ключа требует пересборки EXE.

Если прокси задан, все HTTP-запросы Gemini, включая повторы, выполняются через него. Имена серверов передаются прокси. При ошибке прокси прямое резервное соединение не выполняется. Логин и пароль не поддерживаются. Системные переменные `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY` и `NO_PROXY` не меняют выбранный в приложении маршрут. HTTPS-соединение с Gemini сохраняется через SOCKS-туннель.

Кэш Gemini, извлечённые дорожки и автоматически распакованные утилиты: `%LOCALAPPDATA%\SubsRenamer`. Его можно удалить при закрытом приложении; утилиты восстановятся из EXE, а запросы анализа повторятся. Для тестов/изолированного запуска можно задать `SUBS_RENAMER_DATA`. Настройки Windows хранят модель и адрес прокси; проекты не содержат адрес прокси. Кнопка «Отменить» прерывает ожидание Gemini и закрывает соединение, в том числе при зависшем SOCKS5-прокси или TLS-соединении. Интерфейс остаётся отзывчивым; результаты отменённого запроса не применяются и не попадают в кэш. Таймаут запроса без отмены — 90 секунд.

## Запуск из исходников

Требуются Windows x64 и [uv](https://docs.astral.sh/uv/). Рекомендуемый Python — 3.12.

```powershell
uv sync --python 3.12
Copy-Item .env.example .env
# Заполните GEMINI_API_KEY в .env своим ключом.
uv run python scripts/prepare_vendor.py
uv run subs-renamer
```

`prepare_vendor.py` скачивает официальный MKVToolNix 103.0, проверяет SHA-256, сохраняет лицензии и архив соответствующих исходников. При разработке утилиты берутся из `vendor`, в готовом EXE они встроены. При запуске из исходников ключ читается из `.env` в корне проекта или переменной окружения `GEMINI_API_KEY` (имеет приоритет). Сборщик использует те же источники, не передавая ключ в аргументах командной строки.

## Проверки и сборка

Для пересборки и запуска приложения откройте `rebuild-and-run.cmd` в корне проекта двойным щелчком или выполните `./rebuild-and-run.cmd` в терминале. Скрипт устанавливает зависимости из `uv.lock`, собирает `dist\SubsRenamer.exe` и запускает его только после успешной сборки. Требуются установленный `uv` и ключ Gemini в `.env` или `GEMINI_API_KEY`. Перед пересборкой закройте запущенный EXE.

```powershell
uv run pytest
uv run ruff check src tests scripts
uv run python scripts/live_check.py --proxy socks5://localhost:2080
uv run python scripts/build.py
```

Если предыдущий EXE открыт, можно собрать обновление в другую папку, не закрывая его: `uv run python scripts/build.py --dist-dir dist/updated`.

Живая проверка отправляет только искусственный диалог про Рэна и Лиса. По умолчанию она не входит в тесты. Автотест MKV выполняется после подготовки vendor; без неё явно пропускается. Результат сборки: **dist\SubsRenamer.exe**. В EXE входят две необходимые утилиты MKVToolNix (`mkvmerge`, `mkvextract`), документация, лицензии, соответствующие исходники и уведомления Python-зависимостей. MKVToolNix хранится внутри архивом, чтобы его компоненты не конфликтовали с Qt. Сборка предназначена для Windows x64, без подписи кода.

Для проверки готового EXE без интерфейса можно выполнить `dist\SubsRenamer.exe --self-check report.json`: проверяются встроенный ключ и извлечение русских субтитров из искусственного MKV. Добавление `--live --proxy socks5://localhost:2080` включает живой анализ искусственного диалога. Отчёт содержит только статусы, без ключа. Для обычной работы параметры командной строки не нужны.

В `examples` — два искусственных файла и готовый `demo.subsproject.json`: откройте его через `Ctrl+O`, чтобы попробовать группы имён и ников без обращения к Gemini. Реальные субтитры, API-ключи, проекты, кэш, зависимости и сборки исключены через `.gitignore`. `uv.lock` следует отправить в GitHub вместе с исходниками. Удалённый репозиторий автоматически не создаётся.

Если Gemini возвращает `User location is not supported for the API use`, сервис недоступен для региона текущего подключения. Проверьте настройки своего SOCKS5-прокси и доступность сервиса с его адреса выхода. Ручное редактирование карточек и экспорт работают без API.

## Структура

- `src/subs_renamer`: модели проекта, разбор текста, применение замен, MKVToolNix, Gemini, интерфейс.
- `tests`: сохранность файлов, замены, работа с моделью, сезон из 25 файлов и настоящий многодорожечный MKV.
- `scripts`: подготовка MKVToolNix, сборка, отдельная живая проверка API.
