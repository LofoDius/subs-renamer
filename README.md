# Subs Renamer

Windows-приложение для переименования персонажей в русских субтитрах аниме. Обрабатывает сразу папку сезона: Gemini находит имена, прозвища и их словоформы, а вы проверяете контекст, задаёте новые имена и сохраняете результат.

Например, для замены **Рэн → Иван** приложение помогает составить варианты **Рэна → Ивана**, **Рэну → Ивану** и применить их во всех загруженных сериях. Замены можно исправить вручную и исключить из отдельных реплик.

## Возможности

- Рекурсивная загрузка папки с **ASS, SRT и MKV**; поддержка `.crt` с содержимым SRT.
- Извлечение текстовых субтитров из MKV с выбором дорожки при неоднозначности.
- Поиск имён и прозвищ с Gemini, объединение и разделение карточек персонажей.
- Генерация падежных форм нового имени по найденным контекстам.
- Предпросмотр замен и исключение отдельных вхождений.
- Сохранение отдельными файлами или замена оригиналов, в том числе субтитров внутри MKV без перекодирования видео.
- Сохранение проекта для продолжения работы без повторного анализа.
- Прямое подключение к Gemini или SOCKS5-прокси без авторизации.

Интерфейс написан на PySide6. Для работы с MKV используются `mkvmerge` и `mkvextract` из MKVToolNix.

## Запуск из исходников

Понадобятся **Windows x64**, **Git**, **[uv](https://docs.astral.sh/uv/)** и собственный API-ключ Gemini. Проект поддерживает Python 3.12–3.13; для запуска ниже используется 3.12.

```powershell
git clone https://github.com/LofoDius/subs-renamer.git
cd subs-renamer
uv sync --frozen --python 3.12
Copy-Item .env.example .env
```

Откройте `.env` и заполните ключ:

```dotenv
GEMINI_API_KEY=ваш_ключ
```

Подготовьте утилиты и запустите приложение:

```powershell
uv run python scripts/prepare_vendor.py
uv run subs-renamer
```

Скрипт подготовки скачивает MKVToolNix, проверяет SHA-256 и сохраняет утилиты, документацию, лицензии и соответствующие исходники в `vendor/`. При первом запуске установки понадобится интернет.

Вместо `.env` можно задать переменную окружения `GEMINI_API_KEY`: она имеет приоритет. Ключ нужен для запросов к Gemini; ручное редактирование и экспорт работают без API.

## Попробовать на примере

В папке [`examples`](examples) находятся два искусственных файла субтитров и готовый проект `demo.subsproject.json`.

Запустите приложение и нажмите **Ctrl+O**, чтобы открыть этот проект. В нём можно посмотреть карточки имён, изменить замены и сохранить результат без обращения к Gemini.

## Как пользоваться

1. Нажмите **«Выбрать папку с субтитрами»** или перетащите папку в окно. Приложение загрузит поддерживаемые файлы из неё и подпапок. Уже созданные файлы `.renamed` пропускаются.
2. Для MKV проверьте выбранную дорожку. Единственная русская текстовая дорожка выбирается автоматически; в остальных случаях приложение предложит выбор.
3. Откройте **«Настройки Gemini»**, выберите доступную модель и при необходимости укажите прокси, например `socks5://localhost:2080`. Пустое поле означает прямое подключение. Кнопка обновления повторно загружает список моделей.
4. Нажмите **«Найти имена»**. Проверьте карточки: объединяйте варианты одного персонажа, разделяйте разные имена и добавляйте пропущенные вручную. Для выбора нескольких карточек используйте Ctrl или Shift.
5. Введите **«Новое имя (именительный падеж)»** и нажмите **«Составить варианты с Gemini»**. Проверьте предложенные словоформы: любую замену можно исправить или очистить. Фамилии и прозвища, которые нужно переименовать отдельно, вынесите в отдельную карточку.
6. Проверьте контексты и предпросмотр. Снимите галочки у вхождений, которые относятся к другому персонажу или являются омонимами.
7. Выберите способ сохранения, описанный ниже.

Во время фоновой операции кнопка поиска становится **«Отменить»**. Кнопка **«Изменить папку»** загружает другой сезон и предлагает сохранить текущий проект.

### Сохранение результата

**«Сохранить отдельными файлами»** сохраняет структуру подпапок и создаёт файлы с суффиксом `.renamed`, например:

```text
episode01.srt → episode01.renamed.srt
episode02.mkv → episode02.track3.renamed.srt
```

Оригиналы остаются прежними, существующие результаты не перезаписываются. Рядом создаётся JSON-отчёт о заменах, пропусках и ошибках. При отмене уже записанные файлы остаются в папке назначения.

Отдельные субтитры сохраняются в UTF-8. Вложения со шрифтами из MKV копируются в папку `fonts` рядом с результатом. Для внешнего ASS шрифты нужно подключить в проигрывателе или установить в Windows.

**«Заменить оригинальные файлы»** перезаписывает источники после подтверждения. Для MKV приложение пересобирает контейнер с исправленной дорожкой субтитров без перекодирования видео. Для отдельных субтитров сохраняется исходная кодировка. Перед этим режимом сделайте резервную копию: при ошибке на этапе замены часть файлов уже может быть перезаписана.

### Сохранение проекта

| Сочетание | Действие |
| --- | --- |
| Ctrl+S | Сохранить проект |
| Ctrl+O | Открыть проект |

Файл `.subsproject.json` содержит исходный текст субтитров, карточки, новые имена, замены и исключения. Он позволяет продолжить редактирование без повторного извлечения дорожек и анализа Gemini. Для замены оригиналов исходные файлы должны оставаться доступны.

## Ограничения

- Поддерживаются текстовые субтитры. PGS, VobSub и надписи в самом видео не распознаются; OCR не предусмотрен.
- Gemini может неверно объединить персонажей или предложить неподходящую словоформу. Проверяйте контексты перед сохранением. Род и остальной текст реплики автоматически не переписываются.
- Имена с тегами внутри слова, караоке и векторная графика ASS пропускаются с указанием причины. Обычные теги вокруг имени, тайминги, стили и структура реплик сохраняются.
- При загрузке поддерживаются UTF-8, UTF-16 с BOM и Windows-1251. Другие кодировки нужно предварительно конвертировать.
- Если Gemini блокирует блок текста, анализ продолжается для остальных блоков. Полностью пропущенные файлы выделяются на шаге «Файлы».
- При перекрытии замен выбирается самое длинное совпадение. Замены не каскадируют: результат одной замены не становится входом для следующей.

## Данные и API-ключ

Для анализа в Gemini отправляются тексты выбранных реплик, имена файлов, идентификаторы и кандидаты имён. Видео и шрифты не отправляются. Запросы используют квоту проекта Google, которому принадлежит ваш ключ.

При запуске из исходников ключ читается из `.env` или переменной окружения. **При сборке EXE ключ встраивается внутрь файла и может быть извлечён. Не публикуйте такую сборку и не передавайте её вместе со своим ключом.** Для смены встроенного ключа потребуется пересборка.

`.env`, сборки, зависимости, кэш и рабочие проекты исключены через `.gitignore`. Проекты и отчёты могут содержать исходный текст субтитров — учитывайте это при их передаче другим людям.

Кэш анализа, извлечённые дорожки и распакованные утилиты хранятся в `%LOCALAPPDATA%\SubsRenamer`. Для отдельной папки данных задайте `SUBS_RENAMER_DATA`. Настройки приложения сохраняют модель и адрес прокси.

Если задан SOCKS5-прокси, запросы Gemini идут через него, включая разрешение имени сервера. При отказе прокси приложение не переключается на прямое соединение. Прокси с логином и паролем не поддерживаются; системные `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY` и `NO_PROXY` не меняют выбранный маршрут.

## Сборка EXE

После настройки `.env` выполните:

```powershell
uv run python scripts/build.py
```

Результат — **`dist\SubsRenamer.exe`**. Это один переносимый файл со встроенными Python, Qt, утилитами MKVToolNix и вашим API-ключом. На компьютере запуска не нужны Python и отдельная установка MKVToolNix. Сборка предназначена для Windows x64 и не имеет подписи кода.

Для пересборки и немедленного запуска можно открыть `rebuild-and-run.cmd` двойным щелчком или выполнить:

```powershell
.\rebuild-and-run.cmd
```

Перед пересборкой закройте EXE либо укажите другую папку результата:

```powershell
uv run python scripts/build.py --dist-dir dist/updated
```

## Проверки для разработки

```powershell
uv run pytest
uv run ruff check src tests scripts
```

Тесты проверяют разбор субтитров, замены, экспорт, работу с MKV, обработку ответов Gemini, отмену операций и интерфейс. Интеграционные тесты MKV требуют подготовленных утилит в `vendor/`.

Отдельная проверка настоящего API использует искусственный диалог и расходует квоту Gemini:

```powershell
uv run python scripts/live_check.py --proxy socks5://localhost:2080
```

Диагностика готовой сборки без открытия интерфейса:

```powershell
.\dist\SubsRenamer.exe --self-check report.json
```

Для проверки API из EXE добавьте `--live` и при необходимости `--proxy socks5://localhost:2080`. Диагностический отчёт содержит статусы проверок без значения ключа.
